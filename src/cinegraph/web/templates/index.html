Data sources

IMDb datasets

  • IMDb ID: the identifier used to match movie records.
  • Release year: the year the movie was released.
  • Runtime: movie length in minutes.
  • Genres: the categories assigned to each movie.
  • Rating and votes: community ratings from IMDb.

Kaggle · The Movies Dataset

  • Revenue: the money earned by a movie.
  • Budget: the movie's production cost.
  • Cast: performers in the movie.
  • Director: the person who directed the movie.

OMDb API

  • Plot: a short summary of the movie.
  • Poster: a link to the movie poster.
  • Ratings: IMDb, Rotten Tomatoes, and Metacritic when available.
  • Awards: awards and nominations information.
